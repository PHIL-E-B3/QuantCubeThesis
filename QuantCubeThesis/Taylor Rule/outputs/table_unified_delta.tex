\caption{Out-of-sample forecast evaluation for the rate change target
($\Delta\mathrm{FFR}_{t+1} - \Delta\mathrm{FFR}_t$), one meeting ahead ($h=1$).
\textit{Sample}: $N=151$ FOMC meetings, January 2007--December 2025.
\textit{Protocol}: 50\% initial training window, expanding OLS re-estimated at each step,
$N_{\mathrm{OOS}}=76$ predictions.
\textit{Baseline} (shown once): Macro FAVAR --- PCA on 7 macro regressors
($\hat{\pi}$, $u$-gap, GDP growth, CFNAI, VIX, shadow rate, implied FFR);
RMSE\,$=$\,0.2826 throughout.
\textit{Imp.}: $({\rm RMSE}_{\rm base} - {\rm RMSE}_{\rm model})/{\rm RMSE}_{\rm base}\times 100$.
\textit{Panel A} (Joint PCA): macro and sentiment factors extracted jointly via PCA;
Diebold--Mariano one-sided test ($H_1$: model $\prec$ baseline, i.e.\ lower RMSE).
\textit{Panel B} (Nested FAVAR): macro PCA factors retained from Panel A baseline plus
raw sentiment scores appended as additional OLS regressors; Clark--West test (correct
for nested specification).
\textit{Sub-windows}: RMSE$_{60}$ and RMSE$_{80}$ report RMSE restricted to OOS
predictions with $t\geq\lceil 0.60\,N\rceil$ and $t\geq\lceil 0.80\,N\rceil$,
capturing progressively shorter, more recent evaluation windows.
``---'' denotes $\hat{t}<0$ (model worse) or undefined $p$-value.
$^{***}p<0.01$;\; $^{**}p<0.05$;\; $^{*}p<0.10$.
Bold: lowest RMSE within each method $\times$ architecture block.}
\label{tab:delta_unified}\\
